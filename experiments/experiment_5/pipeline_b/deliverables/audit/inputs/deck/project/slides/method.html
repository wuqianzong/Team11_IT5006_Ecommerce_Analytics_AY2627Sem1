Method

Simple first, time-ordered, one test read

Folds: five chronological, customer-purged folds; no random split on dated orders.

Ladder: dummy → linear / logistic → tree → random forest, then tuning.

Selection: one-SE rule kept the plain linear and logistic models; the forest was within one SE.

Test: A and B frozen first, then scored once together.

Team 11 · IT5006 · Two model families (linear, tree); the forest is the bagged ensemble

Feature selection kept the top features reaching 99% of the cumulative ranking. Class weight is a grid option for the classifiers. The classifier is sigmoid-calibrated, so A and B share one probability scale.

Every learned step, imputation, encoding and scaling, is fitted on the training fold only, inside one pipeline that is cloned for each model, so no statistic from a validation or test order reaches a model. The late tail is real customer experience, so it is kept and modelled on the log scale rather than trimmed. Both pipelines share these steps.
